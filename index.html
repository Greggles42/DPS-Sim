  • 1.32 — NPC front avoidance now uses class-based defense skills (block/parry/riposte/dodge) instead of a flat 8% constant. Each skill is derived from min(level × 5, class_cap) and converted to a chance via EQMacEmu's divisor formula; checks are sequential. Warrior-type mobs (~28% front avoid at level 60) are meaningfully harder to hit from the front than casters (~7%). Inventory Manager: added Save .txt button to export the current inventory in the same tab-separated format as EQ's /outputfile inventory command, so it can be re-imported later. Buff panel: hovering a buff now shows a tooltip with the buff name and all its effects (haste %, ATK, stats, AC, HP). Added Captain Nalot's Quickening (spell 1925, 20% V1 haste, click) to the haste buff list; haste buffs are now ordered ascending by haste %.
    • 
      
  • 1.31 — 2H Weave / fistweave overhaul: weave attempts now fire inline on every mainhand round rather than as a deferred timer event. The offhand cooldown timer is checked at weave time (mainhand swing time + reaction delay); if the offhand is ready, a dual wield check is made — every DW roll counts as one "weave attempt". Only DW successes execute and count as "Rounds (DW check passed)". Offhand cooldown now correctly uses the equipped weapon's delay instead of the hardcoded fist delay (27/16 decisec) for non-epic fistweave and 2H weave. The report now shows: Weave attempts, Blocked by dual wield check, and Rounds (DW check passed). Fixed: Ambidexterity AA now auto-defaults to On for level 65 characters (was checking level === 60, missing PoP-era default level). Fixed: PoP era selection now defaults character level to 65; switching away from PoP resets to 60 if level was exactly 65.
    • 
      
  • 1.30 — Fix backstab to-hit using raw weapon skill instead of the weapon-mod-adjusted value: backstabToHit = 7 + OffenseSkill + min(252, floor(baseSkill × (100 + mod%) / 100)) — weapons with a backstab % modifier (e.g. Bloodbath +12%, Khalshazar +15%) now correctly cap at 252, equalising their to-hit contribution. Advanced mode custom weapons now show a weapon-type selector (1HB / 1HS / 1HP / 2HB / 2HS / 2HP / H2H) next to the damage/delay fields; hidden when a weapon is loaded from item search. Rank Weapons bane fix: low-base-damage bane weapons (e.g. Trident of Slaughter: 1 base + 16 bane) were silently dropped by the damage/delay ratio filter before bane was ever evaluated — they now bypass that filter when their bane race or body type matches the selected target, and bane damage is correctly added during simulation. Additionally fixed a false-positive bane match where weapons with baneDamageBody = 0 (no body bane) were incorrectly treated as having a body bane. Worn ATK cap: combined gear + weapon worn attack bonus is now capped at 250 in both the regular sim and the Rank Weapons engine.
    • 
      
  • 1.29 — BIS Advisor preset tooltip bubbles now appear below the button instead of above, so they are not clipped by the modal header.
    • 
      
  • 1.28 — BIS Advisor: added Custom Weights mode — click the new "Custom" button to replace the priority-order list with a direct numeric weight input per stat (e.g. ATK=10, STR=5). Custom weights use proportional scoring instead of the tier-based priority system. Mode and weights persist to localStorage. Added hover tooltip bubbles on all preset buttons (Melee DPS, Tank, Caster, Ranged) showing the stat priority order and which stats are on/off for that preset.

  • 1.27 — Fix Punishing Blade, Speed of the Knight, Raging Flurry, Knight's Advantage, Tactical Mastery, Soul Abrasion, and Two-Hand Bash AAs: these PoP abilities were built by the AA option builder but never forwarded into the sim options, so they had no effect. All seven are now correctly passed to the sim. Fix attack distribution report: Flurry, Raging Flurry, Punishing Blade, and Speed of the Knight proc counts were missing from the multi-run averaged report object, so those lines never appeared. Flurry and Raging Flurry now appear as sub-lines under Triple attacks; Punishing Blade and Speed of the Knight appear as top-level lines. Mechanics guide: added Punishing Blade AA description (War/Rng/Monk, PoP; 2%/4%/8% chance after double attack, 2H required); corrected Flurry description (fires after triple attack succeeds, not independently).

Previously, weapons with elemental damage (e.g. Great Mace of Slaughter's +1 magic) consumed an extra RNG call on each hit, shifting the RNG stream and causing systematic suppression of mainhand mean hit and crit frequency when such weapons were in the offhand slot. Item debug panel now correctly shows bane amount/body/race for newly loaded items (was showing stale form values). Equipped Items stat pills now appear on a dedicated row below the header line.

Fix 2H Weave: equipping a 2H primary via item search or preset no longer clears the offhand slot when 2H Weave (or monk non-epic fistweave) is enabled.
